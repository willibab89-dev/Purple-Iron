# Badge stat boosts: 5%

Badge stat bonuses are reduced from 12.5% to 5% in both versions. Each eligible stat receives `floor(stat / 20)` extra points, capped at 999. For example, 100 becomes 105 and 150 becomes 157. Stats below 20 receive no bonus because battle stats use whole numbers.

The normal stat calculation and the reconstructed stats used by moves such as Facade, Drill Peck and Waterfall share the same calculation. Existing badge ownership, selective stat rebuilding and critical-hit rules are retained. Boulder boosts Attack, Thunder boosts Defense, Soul boosts Speed and Volcano boosts Special.

Shin’s existing eligibility rules remain: Shift style allows badge boosts in normal trainer and wild battles; Set style allows them only in wild battles. Link battles never apply badge boosts.

This patch includes all previous changes, including the route encounter redesign. Current 183-species saves remain compatible.
