# Pokémon availability check — 28 November 2026

The current roster has 199 species, and each has an identified player-acquisition route in both Red and Blue. Mewtwo requires postgame Cerulean Cave access, and Mew additionally requires the original-150 Pokédex diploma. The numbers describe individual availability; mutually exclusive choices are not guaranteed to all be obtainable in a single playthrough.

The following eight variants now appear only after the first Hall of Fame. Each has a **3% chance per wild encounter** in the specified habitat; the percentage is conditional on an encounter, not per step, and assumes no Repel filtering. Their Pokédex AREA entries appear after the same unlock.
